# 품새 코치

품새 영상을 올리면 관절을 추적해서 서기·발차기·상체·절도를 짚고,
대한민국태권도협회 2026 품새 경기규칙 채점 틀(정확성 4.0 + 표현력 6.0)에 맞춘 **참고 점수**를 냅니다.
영상은 서버로 보내지 않고 **휴대폰 브라우저 안에서만** 분석합니다.

## 써 보기

GitHub Pages 주소(저장소 Settings → Pages에 표시)를 휴대폰으로 열면 됩니다. 설치는 필요 없습니다.

1. **분석** 탭 → 품새 선택 → 영상 선택 → 분석 시작
2. 결과의 지적 사항을 누르면 영상이 그 순간으로 이동합니다.
3. **판정 기준** 탭에서 모든 판정 숫자와 출처를 볼 수 있습니다.

태극 1~6장은 기본 기준 영상이 들어 있어 바로 비교됩니다.
다른 품새나 도장 기준으로 바꾸려면 **기준 영상** 탭에서 시범 영상을 등록하세요(이 기기에만 저장).

### 촬영 요령
- 머리부터 발끝까지 처음부터 끝까지 화면 안에
- 휴대폰은 가슴 높이에 고정, 4~6m 거리, 약간 비스듬히(45°)
- 한 화면에 한 명만

## 테스트에 참여하는 분께

판정이 실제와 다르면 **Issues → New issue → "판정이 이상해요"** 로 알려 주세요.
품새, 몇 초 지점, 앱이 한 말, 실제 상황을 적어 주시면 기준을 고칩니다.
아이 얼굴이 나오는 영상 원본은 올리지 마세요.

## 판정 기준과 출처

| 출처 | 쓰인 곳 |
|---|---|
| 대한민국태권도협회 「2026 태권도 품새 경기규칙」 | 감점(−0.1/−0.3), 시간 90초, 3초 멈춤, 서기 설명, 체중 배분, 발차기 얼굴 높이 |
| WT 국제심판 품새 채점 가이드라인 | 서기 보폭(발 길이 단위) |
| 태극 1~6장 교육영상 측정 | 카메라 오차를 감안한 허용 범위 보정, 기본 기준 영상 |

`refs/*.json`은 교육영상에서 뽑은 **관절 각도 숫자만** 담고 있으며 영상·이미지는 포함하지 않습니다.

## 한계
- 카메라 한 대로 깊이를 추정하므로 몸에 가려진 팔·다리는 오차가 큽니다.
- 뒷굽이와 주춤서기는 두 발 각도로 구분하며, 애매하면 무릎 굽힘만 봅니다. 주춤서기는 아직 시범으로 검증하지 못했습니다.
- 손 모양, 시선, 기합, 손목 굽힘은 판정하지 못합니다.
- **참고 점수는 지도용 추정치이며 실제 심판 채점을 대신할 수 없습니다.**

## 구성
- `index.html` — 앱 전체(화면·분석 로직·판정 기준표 `RULES`)
- `mp/` — MediaPipe Pose 엔진(Apache 2.0, `mp/NOTICE.md` 참고)
- `refs/` — 태극 1~6장 기본 기준(관절 데이터)
